# 从零学习 Spring Boot：图书管理 API

这是一个面向零基础的学习项目。我们会从导入项目开始，逐步完成一个支持增删改查的图书管理 REST API。

当前技术版本：

- Java 8
- Spring Boot 2.7.18
- Maven
- IntelliJ IDEA

## 从这里开始

请打开 [docs/README.md](docs/README.md)，严格按照文档编号依次学习。

第一次运行项目需要完成：

1. [检查开发环境](docs/01-检查开发环境.md)
2. [使用 IDEA 导入项目](docs/02-使用IDEA导入项目.md)
3. [启动项目并访问第一个接口](docs/03-启动项目并访问接口.md)
4. [认识项目目录和基础代码](docs/04-认识项目结构.md)

不要急着背注解。第一阶段的目标只有一个：能够在 IDEA 中成功启动项目，并在浏览器看到 `Hello, Spring Boot!`。
