# 如何重现每一节代码

## 为什么不复制多个 Maven 项目

如果在当前仓库中复制多份完整项目，每份都包含一个 `pom.xml`，IDEA 可能把它们识别成多个 Maven 项目。这样会增加目录、依赖和运行配置的复杂度，不适合零基础学习。

本教程使用 Git 保存每一节的完整代码快照。每完成一节并验证通过后，会同时创建：

1. 一个 Git commit，记录这一节修改了什么。
2. 一个 Git tag，为完成状态取一个容易识别的名字。

Git tag 可以理解为贴在某个 commit 上的固定书签。后面的代码继续变化时，tag 指向的旧代码不会变化。

## 已保存的课程版本

| Tag | 对应内容 |
| --- | --- |
| `lesson-01-hello` | Spring Boot 初始化和 `/hello` 接口 |
| `lesson-02-book-json` | 创建 `Book` 对象并返回 JSON |

## 1. 查看所有课程版本

在 IDEA 底部打开 Terminal，执行：

```bash
git tag --list "lesson-*"
```

预期能够看到：

```text
lesson-01-hello
lesson-02-book-json
```

## 2. 推荐方式：导出一份独立代码副本

这种方式不会改变当前正在学习的代码，最适合初学者。

先在项目根目录创建导出目录：

```bash
mkdir -p exports
```

导出第一节：

```bash
git archive --format=zip --output=exports/lesson-01-hello.zip lesson-01-hello
```

导出第二节：

```bash
git archive --format=zip --output=exports/lesson-02-book-json.zip lesson-02-book-json
```

执行后，`exports` 目录中会出现对应的 ZIP 文件。ZIP 中包含该课程版本当时的完整源码和文档。

`exports/` 已加入 `.gitignore`，导出的压缩包不会被提交到 Git 仓库。

## 3. 解压并用 IDEA 单独打开

以第一节为例：

1. 在 Finder 中找到 `exports/lesson-01-hello.zip`。
2. 双击解压。
3. 建议把解压后的目录重命名为 `lesson-01-hello`。
4. 在 IDEA 中选择 **File → Open**。
5. 选择解压后的目录。
6. 如果 IDEA 询问打开方式，选择 **New Window**。
7. 等待 Maven 导入完成。
8. 确认 Project SDK 和 Maven Runner 都使用 Java 8。
9. 运行 `BookApiApplication`。

这样可以同时保留最新项目和旧章节副本，互不影响。

## 4. 查看某一节修改了什么

查看第一节提交内容：

```bash
git show lesson-01-hello
```

查看第二节提交内容：

```bash
git show lesson-02-book-json
```

命令会显示提交信息和代码差异。按 `q` 可以退出查看界面。

只查看文件列表，可以执行：

```bash
git show --stat lesson-02-book-json
```

## 5. 不推荐初学者直接切换当前目录

Git 也支持把当前工作目录切换到旧 tag：

```bash
git switch --detach lesson-01-hello
```

但这会改变当前目录中的文件，而且在有未提交修改时可能无法切换。初学阶段优先使用 ZIP 导出方式。

如果已经切换到旧 tag，可以通过下面的命令回到最新学习代码：

```bash
git switch main
```

## 每节完成后的保存流程

```text
完成本节代码和文档
        ↓
运行自动测试
        ↓
在浏览器或接口工具中人工验证
        ↓
创建 Git commit
        ↓
创建 lesson 标签
        ↓
进入下一节
```

只有验证通过的代码才会建立课程标签。
