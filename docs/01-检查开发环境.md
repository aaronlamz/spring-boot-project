# 第 1 步：检查开发环境

## 这一节要完成什么

确认电脑已经安装 Java 8、Maven 和 IntelliJ IDEA。

当前学习项目使用 Spring Boot 2.7.18，它可以运行在 Java 8 上。

## 1. 打开终端

在 macOS 上可以这样打开：

1. 按 `Command + 空格` 打开聚焦搜索。
2. 输入 `Terminal` 或“终端”。
3. 按回车。

## 2. 检查 Java

在终端输入下面的命令，然后按回车：

```bash
java -version
```

输出应包含类似内容：

```text
openjdk version "1.8.0_502"
```

`1.8` 就代表 Java 8，因此 Java 环境符合要求。

## 3. 检查 Maven

继续输入：

```bash
mvn -version
```

输出中需要同时看到：

```text
Apache Maven 3.x.x
Java version: 1.8.0_502
```

第一行说明 Maven 已安装；`Java version: 1.8` 说明 Maven 使用的也是 Java 8。

## 4. 确认 IDEA

能够正常打开 IntelliJ IDEA 即可。Community（社区版）和 Ultimate（旗舰版）都能运行这个项目。

## 成功标准

- `java -version` 显示 `1.8`
- `mvn -version` 能正常输出，并显示 Java `1.8`
- IntelliJ IDEA 能正常打开

满足以上三项后，进入[第 2 步：使用 IDEA 导入项目](02-使用IDEA导入项目.md)。

## 常见问题

### 输入命令后提示 command not found

如果 `java` 或 `mvn` 提示 `command not found`，说明对应工具没有安装或没有加入环境变量。请先安装对应工具，并重新打开终端后再次检查。

### Java 显示的不是 1.8

电脑可以同时安装多个 Java。终端和 IDEA 必须分别选择正确的 Java，后面会继续检查 IDEA 的设置。
