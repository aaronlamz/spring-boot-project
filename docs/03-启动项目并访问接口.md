# 第 3 步：启动项目并访问接口

## 这一节要完成什么

在 IDEA 中运行 Spring Boot，并通过浏览器访问 `/hello` 接口。

## 1. 找到启动类

在 IDEA 左侧依次展开：

```text
src
└── main
    └── java
        └── com.example.bookapi
            └── BookApiApplication
```

双击打开 `BookApiApplication.java`。

你会看到：

```java
public static void main(String[] args) {
    SpringApplication.run(BookApiApplication.class, args);
}
```

`main` 是 Java 程序的入口。Spring Boot 从这里启动。

## 2. 运行项目

1. 找到 `main` 方法左侧的绿色三角形。
2. 点击绿色三角形。
3. 点击 **Run 'BookApiApplication'**。

IDEA 底部会打开 Run 窗口并显示启动日志。

首次运行仍可能继续下载少量依赖，请耐心等待。

## 3. 判断启动是否成功

日志中出现类似下面的内容，说明启动成功：

```text
Tomcat started on port(s): 8080
Started BookApiApplication
```

程序启动后不会自动退出，这是正常的。它需要一直运行，才能等待浏览器请求。

## 4. 用浏览器访问接口

不要关闭正在运行的程序。打开 Chrome、Safari 或其他浏览器，在地址栏输入：

```text
http://localhost:8080/hello
```

按回车后应该看到：

```text
Hello, Spring Boot!
```

这里的含义是：

- `http`：使用 HTTP 协议访问
- `localhost`：访问你自己的电脑
- `8080`：Spring Boot 默认监听的端口
- `/hello`：我们编写的接口路径

## 5. 停止项目

回到 IDEA，在底部 Run 窗口点击红色方块按钮。看到程序结束后，项目就停止了。

停止后再次刷新浏览器，网页将无法访问，这是正常现象。

## 6. 可选：使用终端访问

项目运行期间，新开一个 IDEA Terminal，输入：

```bash
curl http://localhost:8080/hello
```

终端也会输出：

```text
Hello, Spring Boot!
```

## 成功标准

- Run 窗口出现 `Started BookApiApplication`
- 浏览器访问 `/hello` 能看到正确文字
- 知道如何停止项目

完成后进入[第 4 步：认识项目结构](04-认识项目结构.md)。

## 常见问题

### 提示 Source option 5 is no longer supported

一般是 Maven 或 IDEA 没有正确读取 `pom.xml`。重新加载 Maven 项目，并确认 Project SDK 与 Maven Runner 都是 Java 8。

### 提示 Port 8080 was already in use

表示已经有程序占用了 8080 端口。先检查 IDEA 中是否重复启动了项目，并停止旧的运行任务。

也可以在 `src/main/resources/application.properties` 中配置其他端口，但现阶段先不要改配置，避免增加额外概念。

### 浏览器显示无法访问

依次确认：

1. IDEA 中的程序仍在运行。
2. Run 日志出现了 `Started BookApiApplication`。
3. 地址是 `http://localhost:8080/hello`，没有拼写错误。

### 浏览器显示 404

404 表示 Spring Boot 已经启动，但没有找到对应路径。确认访问的是 `/hello`，并确认 `HelloController.java` 没有编译错误。
