# 第 4 步：认识项目结构

## 这一节要完成什么

先知道主要文件放在哪里、分别负责什么，不要求立即记住所有注解。

## 项目目录

```text
spring-boot-project
├── docs                              学习文档
├── src
│   ├── main
│   │   └── java                      正式的 Java 代码
│   │       └── com/example/bookapi
│   │           ├── BookApiApplication.java
│   │           └── HelloController.java
│   └── test
│       └── java                      测试代码
│           └── com/example/bookapi
│               └── BookApiApplicationTests.java
├── pom.xml                           Maven 项目配置
└── README.md                         项目入口说明
```

## 1. pom.xml

`pom.xml` 告诉 Maven：

- 项目叫什么
- 使用哪个 Java 版本
- 使用哪个 Spring Boot 版本
- 需要下载哪些依赖
- 如何编译和打包项目

当前两个重要依赖是：

```xml
<artifactId>spring-boot-starter-web</artifactId>
```

它让项目能够接收 HTTP 请求，并自动提供内嵌 Tomcat。

```xml
<artifactId>spring-boot-starter-test</artifactId>
```

它提供编写自动化测试需要的工具。

现在不需要背 Maven 配置，只需要知道新增功能时经常要在 `pom.xml` 添加依赖。

## 2. BookApiApplication.java

这是启动类。

```java
@SpringBootApplication
public class BookApiApplication {
```

`@SpringBootApplication` 告诉 Spring Boot：从这里开始启动，并扫描当前包及其子包中的组件。

因此，后续代码应该放在 `com.example.bookapi` 包或它的子包下。

## 3. HelloController.java

这是目前唯一的 Controller：

```java
@RestController
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello, Spring Boot!";
    }
}
```

逐行理解：

- `@RestController`：这个类可以接收 HTTP 请求，方法返回值直接写入响应。
- `@GetMapping("/hello")`：收到 GET `/hello` 请求时调用下面的方法。
- `public String hello()`：定义一个返回字符串的方法。
- `return ...`：把文字返回给浏览器。

整个过程是：

```text
浏览器访问 GET /hello
          ↓
Spring 找到 @GetMapping("/hello")
          ↓
调用 HelloController.hello()
          ↓
把返回值发送给浏览器
```

## 4. BookApiApplicationTests.java

这是测试类。目前的测试会尝试启动 Spring 容器，用来确认基础配置没有问题。

在项目根目录运行：

```bash
mvn test
```

看到 `BUILD SUCCESS` 表示测试通过。

## 本节需要记住什么

暂时只记住下面四点：

1. `pom.xml` 管理版本和依赖。
2. `BookApiApplication` 是程序入口。
3. Controller 接收请求并返回结果。
4. `/hello` 是请求路径，`hello()` 是处理请求的方法。
