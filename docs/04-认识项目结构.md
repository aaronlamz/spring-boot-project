# 第 4 步：认识项目结构

## 这一节要完成什么

先知道主要文件放在哪里、分别负责什么，不要求立即记住所有注解。

## 项目目录

```text
spring-boot-project
├── docs                              学习文档
├── src
│   ├── main
│   │   └── java                      正式的 Java 代码
│   │       └── com/example/bookapi
│   │           ├── BookApiApplication.java
│   │           └── HelloController.java
│   └── test
│       └── java                      测试代码
│           └── com/example/bookapi
│               └── BookApiApplicationTests.java
├── pom.xml                           Maven 项目配置
└── README.md                         项目入口说明
```

## 1. pom.xml

`pom.xml` 告诉 Maven：

- 项目叫什么
- 使用哪个 Java 版本
- 使用哪个 Spring Boot 版本
- 需要下载哪些依赖
- 如何编译和打包项目

当前两个重要依赖是：

```xml
<artifactId>spring-boot-starter-web</artifactId>
```

它让项目能够接收 HTTP 请求，并自动提供内嵌 Tomcat。

```xml
<artifactId>spring-boot-starter-test</artifactId>
```

它提供编写自动化测试需要的工具。

现在不需要背 Maven 配置，只需要知道新增功能时经常要在 `pom.xml` 添加依赖。

## 2. BookApiApplication.java

这是启动类，完整代码如下：

```java
package com.example.bookapi;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class BookApiApplication {

    public static void main(String[] args) {
        SpringApplication.run(BookApiApplication.class, args);
    }
}
```

逐行理解：

```java
package com.example.bookapi;
```

声明这个类属于 `com.example.bookapi` 包。包用于组织 Java 类，也能避免不同项目中的同名类发生冲突。

```java
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
```

`import` 导入其他包中的类。导入后，代码可以直接写 `SpringApplication`，不必每次都写完整包名。

```java
@SpringBootApplication
```

这是注解。注解以 `@` 开头，用来给类或方法增加额外说明。它告诉 Spring Boot：

- 这是配置和启动入口。
- 根据 Maven 依赖自动配置应用。
- 扫描当前包及其子包中的 Spring 组件。

因此，后续代码应该放在 `com.example.bookapi` 包或它的子包下。

```java
public class BookApiApplication {
```

- `public`：其他代码可以访问这个类。
- `class`：声明一个 Java 类。
- `BookApiApplication`：类名，必须和文件名一致。

```java
public static void main(String[] args) {
```

这是 Java 程序约定的入口方法。点击 IDEA 的运行按钮后，Java 虚拟机会首先调用这个 `main` 方法。

- `public`：Java 虚拟机可以访问它。
- `static`：不需要先创建 `BookApiApplication` 对象就能调用。
- `void`：这个方法没有返回值。
- `main`：Java 规定的入口方法名。
- `String[] args`：接收启动时传入的命令行参数。

```java
SpringApplication.run(BookApiApplication.class, args);
```

这一行把控制权交给 Spring Boot。它会创建 Spring 容器、扫描组件、启动内嵌 Tomcat，并让程序持续监听 HTTP 请求。

### 点击运行后发生了什么

```text
IDEA 启动 Java 虚拟机
        ↓
Java 调用 main 方法
        ↓
SpringApplication.run 启动 Spring Boot
        ↓
Spring 扫描 @RestController 等组件
        ↓
Spring 建立“请求地址 → Java 方法”的映射
        ↓
内嵌 Tomcat 监听 8080 端口
        ↓
程序等待浏览器发送请求
```

日志出现 `Started BookApiApplication` 后，`main` 并不是简单地执行结束。Tomcat 的工作线程仍在运行，所以应用会一直等待请求，直到点击红色方块停止程序。

## 3. HelloController.java

这是第一个 Controller，完整代码如下：

```java
package com.example.bookapi;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello, Spring Boot!";
    }
}
```

逐行理解：

- `package`：说明这个类位于启动类所在的包中，因此能被组件扫描发现。
- 两行 `import`：导入 `@GetMapping` 和 `@RestController` 注解。
- `@RestController`：这个类可以接收 HTTP 请求，方法返回值直接写入响应。
- `@GetMapping("/hello")`：收到 GET `/hello` 请求时调用下面的方法。
- `public String hello()`：定义一个公开方法；返回类型是 `String`，方法名是 `hello`，括号为空表示不接收参数。
- `return ...`：把文字返回给浏览器。

这个方法不是由 `main` 方法直接调用的。应用启动时，Spring 会读取 `@GetMapping` 并记录映射关系；浏览器发来匹配的请求后，再由 Spring 调用 `hello()`。

整个过程是：

```text
浏览器向 localhost:8080 发送 GET /hello
          ↓
Tomcat 接收 HTTP 请求并交给 Spring MVC
          ↓
Spring MVC 找到 @GetMapping("/hello")
          ↓
Spring 调用 HelloController.hello()
          ↓
hello() 返回 String
          ↓
Spring MVC 将字符串写入 HTTP 响应
          ↓
浏览器显示 Hello, Spring Boot!
```

## 4. BookApiApplicationTests.java

完整测试代码如下：

```java
package com.example.bookapi;

import org.junit.jupiter.api.Test;
import org.springframework.boot.test.context.SpringBootTest;

@SpringBootTest
class BookApiApplicationTests {

    @Test
    void contextLoads() {
    }
}
```

- `@SpringBootTest`：运行测试时启动完整的 Spring 容器。
- `@Test`：告诉 JUnit，`contextLoads()` 是一个测试方法。
- 方法体是空的：这里不测试业务结果，只验证 Spring 容器能否成功启动。如果配置或组件存在严重错误，启动失败，测试也会失败。

在项目根目录运行：

```bash
mvn test
```

看到 `BUILD SUCCESS` 表示测试通过。

## 本节需要记住什么

暂时只记住下面四点：

1. `pom.xml` 管理版本和依赖。
2. Java 先执行 `main`，再由 `SpringApplication.run` 启动 Spring Boot。
3. Tomcat 负责监听端口，Spring MVC 负责寻找处理请求的方法。
4. Controller 接收请求并返回结果。
5. `/hello` 是请求路径，`hello()` 是处理请求的方法。
