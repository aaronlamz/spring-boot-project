## 使用方法

请按照编号顺序阅读。每完成一篇文档，再进入下一篇。

每一步都会告诉你：

- 需要做什么
- 在 IDEA 中点哪里
- 应该看到什么
- 每个新增类、方法、注解和关键语句的作用
- 请求进入程序后的完整调用过程
- 如何判断是否成功
- 出错时如何检查
