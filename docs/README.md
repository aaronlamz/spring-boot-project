## 在本地以网页方式阅读

文档可以直接在 IDEA 或 GitHub 里看 Markdown，也可以启动本地文档站，获得侧边栏、全文搜索和上一篇下一篇导航。

第一次使用先安装依赖（需要 Node.js 18 以上）：

```bash
npm install
```

启动本地文档站：

```bash
npm run dev
```

然后访问 `http://localhost:3000`。修改 `docs/` 下任意 Markdown 文件并保存，页面会自动刷新，不需要重启。

停止时在该终端按 `Control + C`。文档站只用于本地阅读，不需要部署，构建产物目录 `doc_build/` 和 `node_modules/` 都不会提交到 Git。
